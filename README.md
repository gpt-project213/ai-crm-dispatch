# AI CRM Dispatch — CRM диспетчеризации со встроенным ИИ

Веб-CRM для управления заказами и диспетчеризацией: заказы, справочники, счета и документы, расходы и зарплаты, выплаты подрядчикам, дашборд, экспорт, аудит действий, роли (администратор, диспетчер, менеджер). Публичная витрина без боевого кода.

## Интеграция ИИ (встроена в систему)

- **ИИ-помощник диспетчера:** чат внутри CRM — составление ответов клиентам, разбор заявок и текстов, вежливые отказы и согласия. Работает через OpenAI-совместимый API, подключаемый провайдер настраивается.
- **Распознавание документов (OCR):** текст с документов распознаётся автоматически, результат всегда проверяет человек. Движок подключается отдельно.
- **Безопасность:** ИИ только предлагает, решение принимает человек; функции отключаемы администратором.

## Статус

Две версии, в обеих встроен ИИ-помощник и распознавание документов:

- **основная** — базовая версия;
- **Pro** — расширенная версия, в эксплуатации у компаний-клиентов, каждая работает на собственном сервере.

## Технологии

Python, FastAPI, SQLite, Alembic, JavaScript-интерфейс, OpenAI-совместимый API, OCR.

## Место в общей системе: дашборд компании

Проект — один из модулей единой ИИ-платформы управления. Все модули отдают данные в общий дашборд руководителя.

| Блок дашборда | Модуль | Статус |
|---|---|---|
| Финансы, дебиторка, продажи | ai-management-dashboard | работает (внутренняя эксплуатация) |
| Задачи, контроль исполнения, совещания | ai-business-assistant | работает (внутренняя эксплуатация) |
| Подбор персонала | ai-recruiter-agent | пилот запущен на сервере |
| Заказы и диспетчеризация | ai-crm-dispatch | в эксплуатации у клиентов (Pro) |
| Данные учёта из 1С | ai-1c-integration | в разработке |

Статусы указаны честно: «дашборд компании» — целевая архитектура, не все блоки ещё подключены.
